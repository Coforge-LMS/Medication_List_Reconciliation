# MedRec 1.0.0

Compare synthetic FHIR, pharmacy and patient-reported medication lists using
duplicate, missing and dosage mismatch rules. Findings support review and
never recommend treatment.

## Features

- Patient search, medication details, grouped findings and PDF reports.
- Saved runs with source snapshots, rejected records and application versions.
- Alias matching and equivalent dose conversion, including 500 mg = 0.5 g.
- Two-source reconciliation when no patient interview is available.
- A local Docker Compose stack and verified PostgreSQL backups.

## Compatibility

Unknown finding types display as `Other (<value>)` in history, run pages and
PDFs. Version rollback keeps the database volume and newer history.

The default backup covers app history and intake. HAPI resources can be
re-imported from committed bundles; preserving exact HAPI resource IDs requires
a separate HAPI database backup.

See the [operations guide](../OPERATIONS.md) for backup and rollback commands.
