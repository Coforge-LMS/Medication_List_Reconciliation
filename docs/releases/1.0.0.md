# MedRec 1.0.0

Initial release of the synthetic medication reconciliation demo: patient-reported
intake, FHIR and pharmacy data are compared using duplicate, missing and dosage
mismatch rules. Runs retain source snapshots and rejected records, support
history and JSON retrieval, and export to PDF. Findings support review and
never recommend treatment.

## Compatibility and operations

- Version is read from `pyproject.toml`; release images are built from annotated
  tags and carry `org.opencontainers.image.version` and `.revision` labels.
- The release Compose entry point uses images without a build section.
- `scripts/backup.sh` stops app writes, restores the archive into
  `medrec_restore_check`, compares all public-table counts, then removes the
  scratch database and restores the app's prior running state.
- Rollback preserves the database volume and newer history. Unknown finding
  types display as `Other (<value>)`; 1.1.0 must introduce no schema changes.
- HAPI data can be re-imported from committed synthetic bundles. The default
  backup covers app-db; exact HAPI resource IDs require a separate HAPI backup.
- The 1.1.0 rollback rehearsal is tracked in TEA-57.
