# MedRec 1.1.0

Adds frequency comparison and offline RxNorm normalization to the three-source
medication reconciliation workflow. Findings flag differences for clinician
review; they never recommend treatment.

## Changes

- Equivalent frequency wording compares consistently. Unknown, missing and PRN
  schedules are not treated as comparable fixed schedules.
- The committed RxNorm cache matches supported brands to their ingredients
  offline. Original source values remain available; strength, salt and form
  differences remain visible. Live RxNav resolution is optional.
- A record matched to its ingredient under another name shows "Matched as" with
  that ingredient on run pages and PDFs.
- A dosage mismatch is reported when sources list the same ingredient at the
  same dose but a different salt or form, so a run that showed no difference in
  1.0.0 can now show one.
- When one source lists two salts of an ingredient, a source lacking one of
  them gets a missing medication finding for that salt.
- Saved run pages and PDFs include a no-differences section listing medications
  every compared source has with no finding. As-needed, unrecognized and blank
  frequencies are explicitly marked as not compared.
- Release builds support both lightweight and annotated tags and verify the
  tagged source version and image revision.

## Compatibility

No schema changes. Rollback replaces only the app container on the same database
volume. Version 1.0.0 retains newer runs and renders frequency findings as
`Other (frequency_mismatch)` with their stored summaries and source values.
Rolling forward restores the full labels.

The published lightweight `v1.0.0` remains unchanged. See the
[release procedure](https://github.com/Coforge-LMS/Medication_List_Reconciliation/blob/main/docs/RELEASING.md)
and [rollback verification](https://github.com/Coforge-LMS/Medication_List_Reconciliation/blob/main/docs/OPERATIONS.md#compatibility-and-rollback).
