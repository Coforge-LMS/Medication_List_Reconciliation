# MedRec 1.1.0

Adds frequency comparison and offline RxNorm normalization to the three-source
medication reconciliation workflow. Findings flag differences for clinician
review; they never recommend treatment.

## Changes

- Equivalent frequency wording compares consistently. Unknown, missing and PRN
  schedules are not treated as comparable fixed schedules.
- The committed RxNorm cache matches supported brands to their ingredients
  offline. Original source values remain available; strength, salt, form and
  route differences remain visible. Live RxNav resolution is optional.
- Saved run pages and PDFs include a no-differences section, with unavailable
  or unrecognized frequencies explicitly marked as not compared.
- Release builds support both lightweight and annotated tags and verify the
  tagged source version and image revision.

## Compatibility

No schema changes. Rollback replaces only the app container on the same database
volume. Version 1.0.0 retains newer runs and renders frequency findings as
`Other (frequency_mismatch)` with their stored summaries and source values.
Rolling forward restores the full labels.

The published lightweight `v1.0.0` remains unchanged. See the
[release procedure](../RELEASING.md) and [rollback verification](../OPERATIONS.md#compatibility-and-rollback).
